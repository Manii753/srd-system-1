# Excel Editor - Quick Start Guide

## 🚀 Getting Started (2 Minutes)

### Step 1: Open Your SRD Form
Navigate to any SRD in your system.

### Step 2: Find the File Attachments
Look for the green pills showing attached files:
```
┌────────────────────────────────────────┐
│ [Specs EXCEL File attached 👁 + ×]    │
│ [Wash Analysis Report 👁 ⬇ + ×]       │
└────────────────────────────────────────┘
```

### Step 3: Click the Eye Icon 👁
This opens the Excel viewer/editor.

### Step 4: Try These Features

#### 📖 **View Mode** (5 seconds)
- Just look at the data
- Scroll through rows
- Switch between sheets

#### ✏️ **Edit Mode** (30 seconds)
1. Click any cell
2. Type new value
3. Press Enter
4. Notice the orange dot: "● Unsaved changes"
5. Click **Save** button
6. See success message! ✅

#### 🖥️ **Fullscreen Mode** (15 seconds)
1. Click the fullscreen button ⛶
2. Enjoy the extra space!
3. Edit as normal
4. Click X to exit

#### 📊 **Multi-Sheet Mode** (20 seconds)
1. Look for sheet tabs at top
2. Click different sheets
3. If you edited something, you'll get a warning
4. Save or switch anyway

## 🔑 Keyboard Shortcuts

| Key | Action |
|-----|--------|
| **Tab** | Move to next cell (right) |
| **Enter** | Submit edit, move down |
| **Esc** | Cancel edit / Exit fullscreen |
| **Click** | Start editing cell |

## ⚠️ Important Notes

### Before Editing
✅ **DO**:
- Save your changes regularly
- Check sheet name before editing
- Verify you're editing the right cell

❌ **DON'T**:
- Switch sheets without saving
- Close the modal with unsaved changes
- Edit if you don't have permissions

### Permissions
- 👁️ **View**: Everyone can view
- ✏️ **Edit**: Only authorized users
- 💾 **Save**: Only with edit permissions

**Check the top of the editor:**
- Green "Save" button = You can edit ✅
- Gray "Read-only mode" = View only 👁️

## 🆘 Troubleshooting

### Problem: Can't see the Excel file
**Solution**: 
- Click the 👁 (eye) icon
- Check your internet connection
- Try downloading instead

### Problem: Can't edit cells
**Solution**:
- Check if you see "Read-only mode"
- Verify you have edit permissions
- Contact admin if needed

### Problem: Changes not saving
**Solution**:
- Click the Save button (don't just close)
- Wait for "Saved successfully" message
- Check network connection

### Problem: Fullscreen won't exit
**Solution**:
- Click the X button in top-right
- Press Esc key
- Click fullscreen button again
